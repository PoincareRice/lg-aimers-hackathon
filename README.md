**LLM Compression for On-Device Inference**

## 📌 개요 (Overview)

최근 AI 서비스는 클라우드 기반의 대규모 모델을 넘어, 노트북·모바일 등 **On-Device 환경**에서도 빠르고 안정적으로 동작하는 **경량 모델**에 대한 요구가 급격히 증가하고 있습니다.  
응답 지연(latency), 메모리 사용량, 운영 비용 등의 제약 속에서 **모델 크기를 줄이면서도 성능을 유지하는 기술**은 핵심 과제로 부상하고 있습니다.

LG AI Research의 **EXAONE**은 Global Frontier급 대규모 모델뿐만 아니라, 제한된 환경에서도 활용 가능한 Small-scale 모델 라인업을 보유하고 있습니다.  
그러나 단순한 파라미터 축소는 메모리·속도 측면에서는 이점이 있으나, **정확도 저하라는 한계**를 동반합니다.

본 해커톤은 이러한 문제의식을 바탕으로, **실제 서비스 환경을 고려한 LLM 경량화 전략을 설계·검증**하는 것을 목표로 합니다.

---

## 🎯 주제 (Task)

**LLM 경량화 (Large Language Model Compression)**

---

## 🧠 문제 설명 (Description)

- 기본 모델: **EXAONE-4.0-1.2B**
- 참가자는 모델 구조와 특성을 분석한 뒤,
  - 양자화(Quantization)
  - 구조적 경량화
  - 필요 시 추가 학습 또는 튜닝  
  등의 기법을 활용하여  
  **모델 크기 · 추론 속도 · 성능 간의 균형을 최적화**해야 합니다.

- 모든 모델은 **vLLM 기반 추론 엔진**에서 동일한 조건으로 평가됩니다.
- 단순한 파라미터 감소가 아닌, **실제 추론 환경에서의 효율성**이 핵심 평가 요소입니다.

## 🚀 해커톤 구성

### Phase 2: 온라인 해커톤

- **vLLM 라이브러리 수정 불가**
- 제출물:
  - Hugging Face 표준 형식의 **모델 가중치 및 설정 파일**
- 평가 방식:
  - 운영진이 제공하는 **고정된 vLLM 추론 환경**에서 실행
  - 동일한 추론 파이프라인 조건 하에서 성능·효율 비교

> 📌 모델 가중치 및 config 수준의 결과물만 평가 대상

---

### Phase 3: 오프라인 해커톤

- **1박 2일 오프라인 진행**
- Phase 2 우수자 중 **약 100명 선발**
- 허용 사항:
  1. Hugging Face 방식의 경량화 모델 가중치
  2. **커스터마이징된 vLLM 라이브러리**

- 가능 예시:
  - 신규 또는 실험적 추론 알고리즘 포팅
  - vLLM에 기본 포함되지 않은 경량화 기법 구현
  - 연산 정밀도 제어 (FP16 / BF16 등)
  - 추론 전략 수준의 최적화

> 📌 추론 엔진 레벨까지 포함한 확장된 최적화 설계 가능

## 📦 코드 제출 방식

- 제출 형식: `submit.zip`
- 포함 파일:
  - Hugging Face 표준 형식의 **모델 가중치 및 설정 파일만**
- 실행 방식:
  - 참가자 코드 ❌
  - 운영진 제공 **고정 추론 스크립트**에서 실행

### ⏱ 실행 환경

| 항목 | 제한 |
|---|---|
| 전체 추론 시간 | ≤ 20분 |
| 제출 파일 용량 | ≤ 10GB (압축 해제 후 ≤ 32GB) |
| CPU | 6 vCPU |
| RAM | 28GB |
| GPU | NVIDIA L4 (22.4GiB VRAM) |

> 📌 상세 내용은 **평가 탭의 코드 제출 가이드** 참고
